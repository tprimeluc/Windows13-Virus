Windows 13 — это образовательный симулятор, который воссоздаёт атмосферу установки и работы в гипотетической операционной системе. Проект демонстрирует:

Реалистичный процесс установки ОС с прогресс-баром и логом операций

Полноценный рабочий стол с панелью задач, меню «Пуск» и виджетами

Встроенные приложения: Проводник, Браузер, Магазин, Настройки

Анимации окон, перетаскивание, системные уведомления

Интерактивные элементы: контекстное меню, системный трей, кнопка «Обновить»

Проект создан для изучения архитектуры оконных приложений, тестирования пользовательских интерфейсов и демонстрации возможностей Python + Tkinter. Он не является вредоносным и предназначен для запуска в изолированной среде.

🚨 Важное предупреждение (обязательно к прочтению)
Данный симулятор содержит экспериментальные функции, которые могут имитировать критические сценарии работы системы.
Запускайте его только на виртуальных машинах или в средах, где не хранятся важные данные.

🧠 Ключевые особенности
Компонент	Описание
Установщик	Полноэкранный мастер с пошаговым логом, имитирует развёртывание Windows 13. Включает 14 этапов установки.
Рабочий стол	Градиентный фон, иконки приложений, контекстное меню (ПКМ), кнопка «Обновить», часы и календарь.
Панель задач	Кнопка «Пуск», список открытых окон, системный трей с индикаторами громкости и сети.
Проводник	Дерево папок, список файлов с реалистичными именами, навигация «вперёд/назад», двойной клик для имитации открытия.
Браузер	Вкладки, адресная строка, кнопка «Перейти» (открывает реальные сайты во внешнем браузере).
Магазин	Список приложений, установка через имитацию, отдельная кнопка для загрузки DirectX 11 (реальный веб-установщик).
Настройки	Категории: Система, Устройства, Сеть, Персонализация, Приложения, Обновление. При клике открывается окно с параметрами.
Анимации	Плавное появление окон (изменение прозрачности), затухание при закрытии, изменение размера.
Уведомления	Всплывающие сообщения в правом нижнем углу с автоматическим исчезновением.
🖥️ Использование
Запустите setup.exe

Установщик предложит начать процесс — нажмите кнопку.

Наблюдайте за прогресс-баром и логом (14 этапов установки).

После завершения установки автоматически загрузится рабочий стол Windows 13.

Исследуйте приложения через иконки на рабочем столе или меню «Пуск».

Проводник позволяет просматривать виртуальную файловую структуру.

Браузер — открывайте вкладки, вводите адреса и переходите по ссылкам.

Магазин — установите DirectX 11, чтобы увидеть реальный процесс загрузки и установки.

Настройки — изменяйте параметры в имитационных окнах.

Через 15 минут после загрузки активируется тестовый режим (для демонстрации экстренных сценариев).

Выключение системы завершает сеанс и запускает процедуру очистки.
